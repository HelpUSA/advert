# MVP Roadmap

## Phase 1 - Foundation
- Next.js frontend shell for Vercel
- Product vision and architecture docs
- Approval-first advertising workflow
- Watcher handoff file

## Phase 2 - Product core
- Brand and profile registry
- Campaign planner
- Content calendar
- Draft generator
- Approval queue

## Phase 3 - Backend
- Railway API service
- Database models
- Audit logs
- Watcher task endpoints

## Phase 4 - Publishing
- Manual publishing checklist first
- Official connectors only where allowed
- Metrics capture and weekly report
- No spam, fake engagement, mass DMs or abusive scraping
