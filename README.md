# Advert HelpUS BR

Owned advertising operations platform for companies, people, services and products.

## Target
https://advert.helpusbr.com

## Stack
- Frontend: Next.js on Vercel
- Backend: Railway API in later phase
- Repository: Git
- Local root: D:/dev/advert

## Current app
The first frontend shell is in apps/web.

## Commands
powershell
Set-Location D:/dev/advert/apps/web
npm run dev
npm run build


## Safety direction
Build owned tools. Prioritize original content, approvals, audit logs and owned channels. Avoid spam, fake engagement, mass DMs, scraping abuse or account manipulation.
